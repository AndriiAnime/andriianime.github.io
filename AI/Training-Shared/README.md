# Останній результат у картці вправи

Обидві версії Alpha 01 на GitHub Pages читають [last-results.json](./last-results.json). Після звіту про тренування або уточнення достатньо оновити **лише цей JSON** на гілці `main`. Повний журнал і коментарі залишаються в Notion.

- Один ключ — останнє виконання вправи або явно названа заміна для цього слота. Однакова вправа в різні дні й у різних темах має один результат. Ключі відповідають ID в `alpha-01-data.js`; винятки: `row2`/`row3` → `row`, `bandrow2`/`bandrow3` → `bandrow`. Підтягування, верхня тяга з кріпленням і домашня тяга до таза мають окремі ключі.
- Записуй дату **заняття** в `date` (YYYY-MM-DD) і підтверджені підходи в `reps` із зазначенням сторони або секунд. `band` — назва чи поєднання кольорів; `load` — інше обтяження; `rir` — технічний запас, якщо відомий. Для заміни впиши фактичну вправу в `as`. Поле `note` — коротке уточнення лише про виконання.
- Пропуск не затирає попередній результат. Неповні підходи не доповнюй припущеннями. `null` означає «не записано», а не нуль чи відсутність резинки. Не замінюй свіжий результат звітом за давнішу дату.
- У файлі публікуються тільки результати вправ. Не додавай сон, симптоми, фото, приватні нотатки чи дані з трекерів. Чернетки з браузера не потрапляють до JSON автоматично.

Перевірка синтаксису перед публікацією: `python -m json.tool AI/Training-Shared/last-results.json > /dev/null` з кореня репозиторію.
