02 · дослідницька ідея

Що готувати для розмови про PhD-роботу

Як подати твою AI/CV-ідею мовою F7

Не просто «застосунок для незрячих», а дослідження гарантоздатної інтелектуальної edge/cloud-системи, де критична асистивна функція має контрольовані затримку, freshness, confidence та поведінку при відмовах.

Робоча назва
«Методи та архітектура гарантоздатної інтелектуальної edge-системи комп’ютерного зору для асистивної навігації людей з порушеннями зору».
2-хвилинна структура
  1. Проблема.
  2. Наукове питання.
  3. Edge/cloud архітектура.
  4. Confidence/freshness/fail-safe.
  5. Метрики: latency, accuracy, offline, unsafe guidance.
  6. Результат: метод/архітектура + експеримент.

1 сторінка concept note

Проблема → question → новизна → метод → експеримент → метрики → результат.

5 слайдів, якщо попросять

Проблема · прогалина · архітектура · метод перевірки · внесок.

03 · база

П’ять тематичних блоків

S · Системне програмування

Суть: як Windows керує пам’яттю, процесами, потоками, синхронізацією, вікнами та real-time задачами.

  • Virtual memory: процес бачить віртуальний адресний простір.
  • Reserve vs commit: діапазон адрес і фактична доступність сторінок — різні речі.
  • Process/thread: процес = ресурси й адресний простір; потік = виконання, стек, контекст.
  • Synchronization: mutex/critical section захищають shared state.
  • Message loop: GetMessage → TranslateMessage → DispatchMessage → window procedure.
  • Real-time: deadline і worst-case важливіші за середній час.
VirtualAllocprocessthreadmutexWin32 APIRTOSdeterminism
M · Мікропроцесорні системи

Суть: взаємодія CPU/MCU з пам’яттю і периферією під часовими та енергетичними обмеженнями.

  • Системна шина: адреса, дані, керування.
  • PCI — розширення; USB — host/device; CAN — контролери; SATA — накопичувачі.
  • Timers/counters та interrupts.
  • Multicore: shared state потребує синхронізації.
  • Embedded: RAM/Flash, енергія, периферія, real-time.
PCIUSBCANSATAtimerinterruptdeadline
N · Мережі та розподілені обчислення

Суть: фізичне з’єднання, доступ до середовища, маршрутизація, захист і рознесення обчислень між вузлами.

  • Wi‑Fi infrastructure/ad-hoc; CSMA/CA + backoff.
  • RIP — distance-vector; OSPF — link-state; BGP — inter-AS.
  • VPN/IPsec захищають вибраний трафік.
  • Flynn: SISD/SIMD/MISD/MIMD.
  • Cloud: IaaS/PaaS/SaaS; edge/cloud split.
802.11CSMA/CARIPOSPFBGPIPsecSIMD
D · Бази даних

Суть: моделювання даних, цілісність, транзакції, серверна логіка, аналітика.

  • PK/FK і referential integrity.
  • DDL vs DML.
  • ACID; COMMIT vs ROLLBACK.
  • Trigger vs stored procedure.
  • Normalization зменшує дублювання та аномалії.
  • Warehouse; Big Data: volume/velocity/variety.
PK/FKDDLDMLACIDtriggernormalizationJDBCADO.NET
P · Проєктування програмних систем

Суть: як із вимог отримати структуровану, тестовану, надійну систему та підтримувати її після релізу.

  • Model описує; pattern задає повторний підхід; framework дає каркас.
  • UML описує структуру/взаємодії.
  • Вимоги мають бути вимірюваними.
  • Black-box / white-box / grey-box.
  • Integration test vs system test.
  • Maintenance: corrective/adaptive/perfective/preventive.
