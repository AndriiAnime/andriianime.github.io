02 · дослідницька ідея

Що готувати для розмови про PhD-роботу

Як подати твою AI/CV-ідею мовою F7

Не просто «застосунок для незрячих», а дослідження гарантоздатної інтелектуальної edge/cloud-системи, де критична асистивна функція має контрольовані затримку, freshness, confidence та поведінку при відмовах.

Робоча назва
«Методи та архітектура гарантоздатної інтелектуальної edge-системи комп’ютерного зору для асистивної навігації людей з порушеннями зору».
2-хвилинна структура
  1. Проблема.
  2. Наукове питання.
  3. Edge/cloud архітектура.
  4. Confidence/freshness/fail-safe.
  5. Метрики: latency, accuracy, offline, unsafe guidance.
  6. Результат: метод/архітектура + експеримент.

1 сторінка concept note

Проблема → question → новизна → метод → експеримент → метрики → результат.

5 слайдів, якщо попросять

Проблема · прогалина · архітектура · метод перевірки · внесок.

Прототип
